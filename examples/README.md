# Примеры использования

## Быстрый режим
**Запрос:** «Используй prompt-improver в режиме Быстро. Улучши: Напиши хороший пост про ИИ».

**Ожидаемое поведение:** Уточнить цель, аудиторию и формат только там, где это существенно; выдать короткий готовый промпт. Не писать сам пост.

## Анализ
**Запрос:** «Используй prompt-improver в режиме Анализ. Улучши: Исследуй влияние ИИ на производительность труда в России».

**Ожидаемое поведение:** Указать на отсутствие периода, метрик и критериев источников; предложить проверяемую постановку задачи, явно помечая неизвестные параметры. Не выполнять исследование.

## Конструктор
**Запрос:** «Используй prompt-improver в режиме Конструктор. Хочу исследовать бизнес-модели и их Canvas».

**Ожидаемое поведение:** Предложить первый заполненный блок, дождаться согласования, затем перейти к следующему. Финальная сборка включает только согласованные версии. Не выполнять исследование.
