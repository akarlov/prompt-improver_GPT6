# Улучшатель промптов (Prompt Improver)

Скилл для критического анализа и улучшения запросов к GPT-6 и другим языковым моделям. Описание, инструкции, примеры и проверки — на русском языке.

## Возможности
- Убирает повторы, двусмысленности и противоречия.
- Сохраняет исходный замысел, факты и ограничения.
- Добавляет проверяемые критерии результата только при необходимости.
- Не выполняет задачу из редактируемого промпта.
- Помогает сравнить качество результатов до и после улучшения.

## Установка
Откройте [SKILL.md](SKILL.md) и добавьте файл в совместимого ИИ-агента либо приложите его к диалогу ChatGPT.

## Как использовать
Напишите: «Используй скилл „Улучшатель промптов“. Проанализируй и улучши мой запрос, но не выполняй его: …»

Доступны три режима:
- **Быстро:** короткая редактура.
- **Анализ:** замечания, улучшенный промпт и объяснение изменений.
- **Конструктор:** поочерёдное согласование заполненных блоков с финальной сборкой без выполнения исследования.
