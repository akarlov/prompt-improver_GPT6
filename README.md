# Prompt Improver

Скилл для критического улучшения промптов на русском языке. Основан на рекомендациях по промптингу GPT-6 и GPT-5.6 из документации OpenAI.

## Что делает
- Сохраняет исходную задачу и факты.
- Устраняет двусмысленности, повторы и противоречия.
- Уточняет формат результата и критерии качества.
- Отделяет анализ промпта от выполнения самой задачи.
- Не усложняет запрос, если он уже достаточно точен.

## Использование
Добавьте [SKILL.md](SKILL.md) в совместимого агента или приложите его в ChatGPT.

Пример: «Используй prompt-improver. Улучши мой промпт, но не выполняй его: ...»

## Режимы
**Быстро** — минимальная редактура. **Анализ** — критический разбор и готовый промпт. **Конструктор** — согласование заполненных блоков по очереди.

Примеры — в [examples](examples/).

## Источник
Адаптация пользовательского PDF «Using GPT-6 | OpenAI API», разделов Prompting best practices для GPT-6 и GPT-5.6. Это независимый скилл, не официальный продукт OpenAI.
